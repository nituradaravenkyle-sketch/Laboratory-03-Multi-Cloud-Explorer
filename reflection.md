# Reflection

Through this laboratory activity, I learned about the differences between AWS, Microsoft Azure, and Google Cloud Platform. I learned that each cloud provider offers different services and has its own strengths.

I also learned that cloud computing can help businesses store data, run applications, and manage their resources without depending only on physical computers. Comparing the three platforms helped me understand why choosing the right cloud provider is important for a business.

Among the three platforms, I found AWS interesting because it offers many different services. However, I also learned that Azure can be a better choice for organizations using Microsoft products, while GCP is useful for data analytics and AI.

Overall, this activity improved my understanding of cloud computing and helped me see how cloud platforms can be used in real-world businesses.
