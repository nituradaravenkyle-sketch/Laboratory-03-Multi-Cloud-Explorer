
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides different services for computing, storage, networking, databases, security, and other IT needs. It allows businesses and organizations to use cloud resources without having to maintain their own physical servers.

## Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. These locations allow businesses to deploy their applications and services in different parts of the world. This helps improve application availability, performance, and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and manage their cloud resources through the console.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files, data, backups, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a private network for their AWS resources. It provides control over networking and communication between cloud resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) allows administrators to manage users, roles, permissions, and access to AWS resources.

## Three Advantages

1. **Wide Range of Services** – AWS provides many services for computing, storage, databases, networking, security, and other business needs.
2. **Scalability** – AWS allows organizations to increase or decrease cloud resources depending on their requirements.
3. **Global Infrastructure** – AWS has infrastructure in different regions around the world, allowing applications to serve users from different locations.

## Typical Enterprise Use Cases

AWS can be used by enterprises for web applications, mobile applications, data storage, database systems, backup and recovery, business applications, and large-scale IT infrastructure.
